# 应用启动预连接与空闲会话恢复

## 行为

此前 `prewarm()` 是空实现。下载完成后虽然保留 SteamCMD，但应用第一次启动、空闲进程退出后仍需等用户下载时才建立连接。

- 在应用启动回调中、桌面和壁纸库加载之前开始预连接，不依赖打开创意工坊或点击下载。初始化在后台执行。
- 三个独立会话依次完成登录；一个会话就绪后即可下载，其余继续准备。调度优先使用已登录的空闲槽位，最多三项同时下载。
- 应用运行期间保留空闲连接。每 15 秒检查进程退出和已报告的断连状态，自动补回空闲会话；不向正在下载的会话插入维护命令。
- 网络连接失败按 30、60、120、240、300 秒退避，避免频繁登录。账号授权失效时停止后台重试，重新登录成功后恢复预连接。
- 从睡眠唤醒时立即检查连接；应用退出时停止维护并清理进程。
- 下载中心显示已连接数量及后台连接状态。

## 验证

- Swift 测试 133 项：129 项通过，4 项需显式启用的外部集成测试跳过。
- 进程级测试覆盖：无下载任务时建立三个会话、重复预热不创建额外进程、首个下载复用空闲进程、空闲进程退出自动补回、故障退避、退出后停止重试、预连接期间进入的下载不共用同一初始化槽位。
- 当前 Shadowrocket 配置下，独立临时目录的真实下载验收通过：首次后台连接约 49.005 秒；连接就绪后，第一张进入下载准备约 0.0022 秒，第二张约 0.0027 秒，两张均完成并校验主文件，复用同一实际进程。
- 另一次冷启动遇到登录超时，维护逻辑退避后恢复。预连接减少下载前反复登录的等待，首次服务器连接仍受当前网络影响。

真实验收使用临时壁纸库，不改变用户订阅：

```sh
LW_STEAMCMD_SPEED_INTEGRATION=1 LW_STEAMCMD_PREWARM_INTEGRATION=1 \
  DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  swift test --filter WorkshopDownloaderTests.testLiveWarmSessionAvoidsSecondLogin
```
