# 创意工坊可靠性修复（2026-11-03）

基线：`wip-gap-completion-20260614` / `7588145`，与 v0.1.0 Release 一致。
远端 main 较旧；本次核对的两个远端分支没有更新的修复提交。

## 发现与修复

- Homebrew Cask 的入口位于 `.homebrew-command-wrappers/steamcmd`。旧路径推导找不到同级的 `MacOS/steamcmd`，回退到了多层 shell。现在正确定位二进制并继续补齐动态库环境。
- 登录阶段的进程纳入取消管理；退出时阻止后续排队任务重启会话。
- 识别 Steam 明确返回的连接失败与缺失凭据，区分网络故障和下载登录过期。工坊页面提供重新登录入口。
- 下载已开始但第一块始终未到时也会超时；开始信息不再反复把传输状态改回准备状态。
- 重启会话后，旧进程的异步输出及终止回调不再污染新会话。
- CrossOver 的历史 ACF 记录不再直接视为接管本次任务，使用本次日志或清单变化判断。
- 工坊页面加载失败显示错误和重试入口；处理新窗口链接。
- 筛选菜单的 dialog 与页面视口使用相同坐标系，针对菜单/列表角色处理，不依赖 Steam 动态类名或固定像素偏移。限制在 HTTPS Steam Community 主页面生效。
- 构建优先使用已安装的完整 Xcode，避免 Command Line Tools 缺 SwiftUI 宏插件。

## 验证及限制

- 下载、CrossOver、网页授权和 WebKit 菜单坐标测试：24 项，23 项通过，1 项可选联网检查默认跳过。
- WebKit 菜单夹具检查滚动及窗口缩放后的视口和菜单坐标。
- 本机实际 SteamCMD 匿名登录成功；配置的下载账号缺少可用缓存凭据。
- 联网下载探针仍遇到连接失败，未确认真实壁纸下载成功。需要用户在应用内重新登录下载账号，之后继续实测。
- 旧应用备份：`~/Downloads/LiveWallpaper-v0.1.0-backup.app`。

凭据不写入本说明；不要将本机 Steam 配置、Cookie 或运行日志提交到仓库。
